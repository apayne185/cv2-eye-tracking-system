# Bundled assets

## canonical_face_model.obj

MediaPipe's canonical face model: 468 vertices matching the FaceMesh
landmark topology, used as the 3D reference for head-pose estimation
(`eyetrack.head_pose`).

- **Source:** [google/mediapipe v0.10.9, `mediapipe/modules/face_geometry/data/canonical_face_model.obj`](https://github.com/google/mediapipe/blob/v0.10.9/mediapipe/modules/face_geometry/data/canonical_face_model.obj)
