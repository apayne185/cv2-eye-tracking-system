# Attention-zone evaluation on real video

3165 frames from 14 subjects (3121 with a usable face). Generated by `scripts/evaluate_zones.py` from `datasets/real_clips/manifest.csv`; see that folder's README for label definitions and limitations.

**System** scores every frame, treating frames with no detected face as `away`. **Classifier** scores only frames with a usable face. Real-data models use leave-one-subject-out: each person is predicted by a model that never saw them. Macro-F1 averages the per-class F1 over classes present, so the large `on_screen` class can't hide a weak one.
